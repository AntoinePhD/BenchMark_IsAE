## Overview

This repository accompanies the paper **"IsAE: A Fast and Generalisable Neural Network for Detecting AE in Laboratory Experiments."** It provides the complete codebase, trained model weights, and evaluation dataset needed to reproduce all figures and results presented in the manuscript.

**IsAE** is a deep convolutional neural network (DCNN) for fast and generalizable acoustic emission (AE) event detection in laboratory experiments. It uses a semi-supervised training approach — an unsupervised encoder-decoder paired with a supervised classifier — trained entirely on synthetic data, overcoming the scarcity of large annotated AE datasets. The model focuses on amplitude evolution patterns rather than absolute values, enabling consistent performance across diverse experimental conditions without retraining.

Key capabilities:
- **Fast, near-real-time detection** on continuous high-sample-rate data streams
- **Noise discrimination** — naturally filters irrelevant noise, serving as a reliable prefilter for phase-picking algorithms
- **Generalizable** — works across different rock types and experimental setups without retraining
- **Data-efficient** — reduces storage demands by selectively saving only AE-containing windows, enabling longer experiments

## Method Summary

### Architecture

IsAE consists of two phases:

1. **Phase 1 — Unsupervised encoder-decoder training:** A 2D convolutional autoencoder is trained on synthetic data (5,000 AE waveforms + 5,000 noise samples) to compress the 2D time-slice representation (250 × 254 matrix) into a 1,280-parameter latent space. The encoder learns to represent the essential structure of the signal without supervision.

2. **Phase 2 — Supervised classifier training:** A classifier composed of three linear layers is trained on the frozen encoder output to produce a two-class probability (AE vs. noise) via a softmax function.

### Input representation

Waveforms are transformed into a 2D time-slice representation:
- Each waveform segment is windowed with a Hanning window
- 250 points per window with 80% overlap
- Reassembled column-wise to form a 2D matrix (time × slice number), with amplitude encoded as intensity
- Final input size: 250 × 254 points

This pre-spectrogram representation captures amplitude evolution patterns without requiring a full spectrogram computation.

### Synthetic dataset

Training data is generated entirely synthetically:
- Green's function generated from a random sparse vector (Aki & Richards formulation)
- Convolved with a Gaussian wavelet
- Multiplied by a Gaussian envelope with varying center and width
- Gaussian noise added (σ = 1.5)

This ensures the model remains unspecialized and generalizes across diverse source events (intact rock, shearing fault gouge, etc.).

## Comparison with Published Architectures

The paper benchmarks IsAE against five published neural networks from the seismology literature:

- **PhaseNet** (Zhu & Beroza, 2019)
- **OBSTransformer** (Niksejel & Zhang, 2024)
- **EQTransformer** (Mousavi et al., 2020)
- **GPD** (Ross et al., 2018)
- **CRED** (Mousavi et al., 2019)

Evaluation metrics include accuracy, balanced accuracy, recall, and F1-score across three datasets — the author's Quartz/Westerly Granite dataset, plus the MinUSil and Glass Bead datasets from Mastella et al. (2026) — with analysis of the best probability threshold for each model.

---

## Performance Highlights

- **Competitive accuracy** with significantly fewer parameters than transformer-based models
- **Fast inference** — capable of processing continuous data streams on a moderately efficient laptop
- **Denoising capability** — the encoder-decoder can suppress electrical noise and reveal hidden AE signals (see Figure 12 in the paper)
- **Generalization** — trained only on synthetic data, performs well on real laboratory datasets from different rock types
